# Dhiraj Jadhav — Datablyst Portfolio

Dynamic Data Analytics portfolio built with React + TypeScript + Vite. Includes responsive navigation, project filtering, GitHub links, certificates, resume and contact links.

## Run locally

`npm install`

`npm run dev`

## Build

`npm run build`

## Deploy

Import this repository into Vercel. The project uses Vite and requires no API keys or backend services.
